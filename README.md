# Simon-Say-s-Game

A simple Simon Says memory game built using HTML, CSS, and JavaScript.

## How to Play

* Start the game.
* Remember the color sequence.
* Repeat the sequence by clicking the buttons.
* The sequence gets longer with each round.
* Click the wrong button and the game ends.

## Technologies

* HTML
* CSS
* JavaScript

## Run Locally

Clone the repository and open `index.html` in your browser.
